Foundry Enhanced UI (ou Better Suite, comme je l'ai appelé dans le code) est un module pour Foundry VTT né d'une volonté simple : l'interface par défaut du logiciel est fonctionnelle, mais assez rebutante pour les nouveaux joueurs, inutilement compliquée à naviguer et surtout pas très esthétique.

Le module regroupe une liste de joueurs ancrable (avec PNJ, notes, partage d'images et suivi de combat intégré), un plateau à dés flottant, un chat retravaillé, une interface épurée, et une barre d'actions de combat inspirée de Solasta. Chaque brique s'active ou se désactive indépendamment, avec un système de thème de couleur centralisé pour que l'ensemble reste cohérent.

C'est un projet à la croisée de mes deux mondes : du dev avec de l'architecture logicielle d'un côté, du game design et de la maîtrise de jeu de l'autre. Rien de tel qu'un vrai besoin à la table pour tester du code en conditions réelles, semaine après semaine.

Compatible Foundry VTT v11/v12, système dnd5e. Le code est open source.
